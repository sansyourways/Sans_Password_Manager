# Contributor License Policy

Sans Password Manager accepts contributions under the Apache License 2.0 and
the Developer Certificate of Origin 1.1 (`DCO`).

## Ordinary contributions

By intentionally submitting a contribution for inclusion in SPM, you license
it under Apache-2.0 as described by section 5 of `LICENSE`. You retain copyright
in your work. Every commit must also carry a DCO sign-off created with:

```bash
git commit --signoff
```

The sign-off certifies the statements in `DCO`; it is not a copyright
assignment. Do not sign off work you are not authorized to contribute.

## Substantial contributions

For unusually large, strategically important, or organization-owned
contributions, maintainers may require a separate written contributor license
agreement before merging. Any such agreement will be presented for review in
advance. It does not apply retroactively merely because a pull request was
opened.

## Third-party material

Identify third-party code, assets, or documentation in the pull request and
include its source and license. Contributions with incompatible or unclear
provenance will not be accepted.
