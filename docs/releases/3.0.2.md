## Upgrading

This is a client-side Dashboard fix. It does not change the vault format,
recovery material, stored records, CLI commands, or migration behavior. Users
coming from 3.0.0 or 3.0.1 can upgrade in place.

If the SPM Dashboard is already installed on the iOS Home Screen, fully close
and reopen it after the server is upgraded so WebKit discards the old page.

## Fixed

**The mobile hamburger button opens the navigation drawer in the installed iOS
web app again.**

The button previously depended on one document-level delegated click listener.
That listener called `closest()` directly on the event target; an iOS/PWA tap
can surface the icon's SVG `<use>` node instead of the surrounding button, so
the action lookup could fail before the drawer toggle ran.

The hamburger button and drawer backdrop now have direct click listeners. The
remaining delegated controls defensively normalize their event target before
using `closest()`. The button also declares `type="button"`, `aria-controls`,
and its existing `aria-expanded` state.
