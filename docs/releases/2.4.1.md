## [2.4.1] - 2025-12-13

### Fixed
- Web mode now keeps passphrases and backup codes out of the password entries list so each item only shows in its dedicated section.

### Release steps
1) Update version + docs: `VERSION=2.4.1`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.4.1.zip spm.sh README.md docs release-2.4.1.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.4.1"
   git tag v2.4.1
   git push origin main --tags
   ```
4) Create GitHub release for `v2.4.1` attaching `Sans_Password_Manager_v2.4.1.zip` and include the changelog notes above.
