## [2.7.8] - 2025-12-13

### Added
- Export now supports toml, org, scsv (semicolon CSV), csv-noheader, and jsonc on top of existing formats. Menu prompt lists all available formats while still highlighting csv/json.
- Web authenticator live view now shows a clipboard button so OTP codes can be copied instantly.
- Web import form now overlays the entire Export/Import card while uploading and shows inline success/error feedback without redirecting the user.
- Removed deprecated `cgi` usage from the web server; multipart uploads now rely on the internal boundary-aware parser (no Python 3.13 warnings).

### Changed
- Version bumped to 2.7.8.

### Fixed
- Import endpoint now reuses the already-read request body instead of attempting to read the stream twice, preventing uploads from hanging on “load failed”.
- Web import form no longer registers duplicate submit handlers, so only a single upload is issued per click (no phantom retries or stuck loaders).
- Import now validates that at least one record was parsed from the uploaded file and raises a helpful error instead of silently doing nothing.
- Successful web imports now auto-refresh the dashboard so the newly added passwords/notes/passphrases/backups/authenticators are visible immediately.
- JSON responses now include per-type counts so the UI can display exactly what was imported.
- Importer now writes real tab/newline delimiters instead of literal `\t`/`\n`, so newly added rows appear across CLI + web immediately.

### Release steps
1) Package ZIP:  
   ```bash
   zip -r Sans_Password_Manager_v2.7.8.zip spm.sh README.md CHANGELOG.md
   ```
2) Commit/tag:  
   ```bash
   git add spm.sh README.md CHANGELOG.md release-2.7.8.md AGENTS.md docs
   git commit -m "release: v2.7.8"
   git tag v2.7.8
   git push origin main --tags
   ```
3) Publish GitHub release `v2.7.8` attaching the ZIP with the notes above.
