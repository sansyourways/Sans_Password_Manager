# Sans Password Manager 5.0.1

A Dashboard fix, no format change — 5.0.1 reads and writes exactly the vaults
5.0.0 does.

## The bug

The language picker on the sign-in page drew each language's flag as an emoji.
A flag emoji is a pair of "regional indicator" characters (🇬🇧 is 🇬 + 🇧), and
desktop Windows ships no flag glyphs — so Chrome and Edge on Windows render the
pair as the two country letters instead: English as **GB**, Indonesian as
**ID**, and so on. Phones and macOS were fine because their system fonts carry
the glyphs, which is why it looked correct on one device and wrong on another.

## The fix

Flags are now **inline SVG**, drawn from a small bundled sprite, so they render
identically on Windows, macOS, Linux, iOS and Android — no dependence on an OS
emoji font.

The picker keeps working the way it did:

- The native `<select>` is still there as the fallback for no-JavaScript and
  assistive technology. It now carries only the language's own name, so even
  without the enhancement it reads cleanly — no stray "GB".
- With JavaScript, an **accessible listbox** takes over: full keyboard support
  (arrows, Home/End, Enter, Escape, type-ahead), correct ARIA roles, and a flag
  beside each language. Right-to-left languages place the flag on the reading
  side.

Nothing about the twelve languages, their translations, or the vault changed.
The emoji flag stays in each locale's metadata — the i18n lint still requires
it to be two regional indicators — and the country it names is what keys the
SVG sprite, so adding a language is still a metadata entry plus its flag.

## Testing

The regression suite now asserts, over real HTTP, that the served sign-in page
draws an SVG flag for the active language, carries the flag sprite, presents
the enhanced combobox, and that **no regional-indicator emoji reaches the page
at all** — which is the bug, stated as a test. The accessibility check that
every form control is named continues to pass.

## Upgrading

Nothing to do. Reinstall or redeploy the Dashboard and the picker shows flags.
Your vault is untouched.
