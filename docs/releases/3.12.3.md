# Sans Password Manager 3.12.3

This documentation patch adds a complete visual product tour and makes safe
removal instructions explicit.

## Every Dashboard page in one showcase

The README now contains one animated showcase instead of a screenshot gallery.
Its 31 frames cover login, every Dashboard GET page, Security Events, and the
locked-vault state. Chromium captured the release candidate on this device
using a disposable profile and synthetic vault only. Names, `.invalid`
hostnames, passwords, tokens, backup codes, and recovery material are fixtures;
no personal or production data appears in the media.

## Complete uninstall boundaries

The README now distinguishes application-only removal from irreversible data
removal, including custom install prefixes, PATH entries, PM2, browser native
hosts, Nginx, TLS certificates, vaults, recovery material, backups, sync
targets, and emergency kits. SPM still provides no blanket deletion command.

The README also corrects Apache 2.0 labeling, XDG path notation, and recovery
private-key bundle behavior.

## Compatibility

No vault-format, cryptography, command, dashboard, extension, import/export, or
network behavior changes. Rolling back to 3.12.2 requires no vault migration.
