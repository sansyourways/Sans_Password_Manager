# Sans Password Manager 5.10.1

A follow-up fix. No vault format change, and existing vaults are untouched.

## A dedicated page for each record type

The sidebar's Records entry expands into one sub-entry per record type — Credit
Card, Certificate, API Token, Database Credentials, GPG Key, Identity Document,
Server, Wi-Fi Network, SSH Key, Software Licence. Clicking one already filtered
the list to that type, but the page it produced was still the generic **Records**
page: the same "Records" heading, the same "+ Add Record" button that opens the
type picker, and a Type column repeating the same word on every row. So a type's
sub-page looked and behaved like the combined list, not a page of its own.

Each type page is now genuinely dedicated:

- the **heading is the type's own name** (localised), not "Records";
- **"+ Add" goes straight to that type's form** rather than the picker;
- the redundant **Type column is dropped** (every row is that type);
- the empty state points at adding the first record of that type.

The combined **All** page — Records with no type chosen — is unchanged: it keeps
the Type column and the generic heading, and lists every type together.

This corrects an earlier status note that called the per-type pages
already-implemented. Only half of it was: the filtering worked, but the page was
not dedicated.

## Upgrading

Reinstall or redeploy. Nothing about how vaults are written changes.
