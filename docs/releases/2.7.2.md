## [2.7.2] - 2025-12-13

### Changed
- Tables/lists now follow theme colors (backgrounds, borders, text), improving readability; Light theme uses soft whites/grays instead of dark rows.

### Release steps
1) Update version + docs: `VERSION=2.7.2`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.7.2.zip spm.sh README.md docs release-2.7.2.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.7.2"
   git tag v2.7.2
   git push origin main --tags
   ```
4) Create GitHub release for `v2.7.2` attaching `Sans_Password_Manager_v2.7.2.zip` and include the changelog notes above.
