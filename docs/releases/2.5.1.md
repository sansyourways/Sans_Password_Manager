## [2.5.1] - 2025-12-13

### Added
- Autofill bookmarklet endpoint (`/autofill`) for password entries; copy buttons on password, secure note, passphrase, and backup views.

### Changed
- Web password view now offers quick copy for username/password/notes and bookmarklet generation for browser autofill.

### Release steps
1) Update version + docs: `VERSION=2.5.1`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.5.1.zip spm.sh README.md docs release-2.5.1.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.5.1"
   git tag v2.5.1
   git push origin main --tags
   ```
4) Create GitHub release for `v2.5.1` attaching `Sans_Password_Manager_v2.5.1.zip` and include the changelog notes above.
