## [2.7.4] - 2025-12-13

### Changed
- Primary/add buttons now use a pastel blue gradient with themed borders across password, passphrase, generator, TOTP, and backup sections for a cleaner light theme experience.

### Release steps
1) Update version + docs: `VERSION=2.7.4`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.7.4.zip spm.sh README.md docs release-2.7.4.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.7.4"
   git tag v2.7.4
   git push origin main --tags
   ```
4) Create GitHub release for `v2.7.4` attaching `Sans_Password_Manager_v2.7.4.zip` and include the changelog notes above.
