### Added
- Export supports csv, json, tsv, ndjson, markdown, html, and txt from both CLI and the interactive menu.

### Changed
- Version bumped to 2.7.6.

### Release steps
1) Ensure version/docs updated (done): `VERSION=2.7.6`, README export formats, CHANGELOG.
2) Package release ZIP:  
   ```bash
   zip -r Sans_Password_Manager_v2.7.6.zip spm.sh README.md docs CHANGELOG.md LICENSE
   ```
3) Commit and tag:  
   ```bash
   git add spm.sh README.md CHANGELOG.md release-2.7.6.md AGENTS.md docs
   git commit -m "release: v2.7.6"
   git tag v2.7.6
   git push origin main --tags
   ```
4) Publish GitHub release for `v2.7.6` attaching `Sans_Password_Manager_v2.7.6.zip` with the notes above.
