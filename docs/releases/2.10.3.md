# Sans Password Manager 2.10.3

SPM is now an open-source project under the Apache License 2.0.

- Replaced the former private license with the standard Apache-2.0 license
- Added copyright attribution and an Apache `NOTICE`
- Opened the contribution workflow under Apache-2.0 and DCO 1.1 sign-offs
- Added contributor-license and trademark policies
- Aligned the README, Code of Conduct, security policy, terms, issue forms, and
  pull-request template with open-source collaboration
- Included `LICENSE`, `NOTICE`, and `DCO` in the immutable release archive

This governance-only patch does not change vault formats, encryption behavior,
or the web interface. Releases published before 2.10.3 remain under the license
included with those historical artifacts.
