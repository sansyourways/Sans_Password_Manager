# Sans Password Manager 3.12.4

This release adds four selectable Dashboard themes, consolidates settings, and
makes password folders and tags practical navigation tools.

## Dashboard themes

Settings now offers Sundial, Console, Cyberpunk, and Edgerunner with a preview
before applying. The selected theme stays on this browser and follows the
sign-in and locked-vault screens. Cyberpunk uses a right-side HUD, while
Edgerunner uses a responsive command dock with compact desktop controls and
full labels on wide displays. Motion is disabled when reduced motion is
requested.

## Password organization

The Passwords page now has a dedicated organization panel. One or more folders
and `#tags` can be combined, active values have a visible checkmark, and the
result count and clear action remain available. Filter state is encoded with
repeated `folder` and `tag` query parameters, so it survives reloads, bookmarks,
and browser navigation. Filtering happens on the local Dashboard server after
the vault is unlocked; no record data is sent elsewhere.

## Compatibility and rollback

There is no vault-format or cryptographic migration in this release. Rolling
back to 3.12.3 does not require a vault conversion, although that version does
not expose the new theme or organization interfaces.

## Verification

The release candidate passed the complete regression suite covering the trusted
core, real multipart and pasted imports, WebAuthn, accessibility, reproducible
archives and packages, concurrent writes, and all 20 import/export formats.
