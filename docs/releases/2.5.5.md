## [2.5.5] - 2025-12-13

### Changed
- Bookmarklet now targets more username/email selectors (mail/email/account/identifier) and falls back to the first text field to improve autofill success.

### Release steps
1) Update version + docs: `VERSION=2.5.5`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.5.5.zip spm.sh README.md docs release-2.5.5.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.5.5"
   git tag v2.5.5
   git push origin main --tags
   ```
4) Create GitHub release for `v2.5.5` attaching `Sans_Password_Manager_v2.5.5.zip` and include the changelog notes above.
