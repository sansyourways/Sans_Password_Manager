# Sans Password Manager 3.1.0

SPM 3.1.0 turns the original record-ID Chromium bridge into a practical,
cross-browser account picker. Chrome, Chromium, Edge, Brave, Opera, Vivaldi,
and Firefox desktop now share one extension source tree and one deliberately
small vault boundary.

## What changes

Open an HTTP(S) login page, select the SPM toolbar icon, unlock once, and choose
one of the accounts bound to that exact hostname. SPM fills only after an
explicit account selection. A record for `example.com` is not offered on
`login.example.com`, and the CLI verifies the active hostname again when the
selected credential is retrieved.

The new `spm bridge-list <host>` operation makes the picker possible without
turning account discovery into a password oracle. It returns record ID, label,
username, and URL only. Password and notes fields never appear in its response.

## Session and security model

- The master password is sent only to the local native host and the local SPM
  process; it is never written to extension storage or disk.
- Unlock state is a process-memory reference, not a reusable bearer token or a
  new daemon.
- Explicit lock, five idle minutes, the twelve-hour absolute cap, native-port
  disconnect, and browser exit all discard the session.
- Native messages are size-limited and hostnames and record IDs are validated.
- The original one-shot extension protocol remains accepted during migration.

This release does not add silent autofill, wildcard parent-domain matching,
cross-origin iframe filling, or save-on-submit. Those surfaces need separate
origin and phishing controls and remain intentionally outside 3.1.0.

## Install the extension

After installing SPM and unpacking this release, follow **Install the browser
extension** in the main README. It covers building the Chromium or Firefox
variant, loading it in developer mode, registering the native host, and using
unlock/fill/lock.

Safari requires a separately signed Xcode application wrapper and cannot load
this native-messaging package. iOS browsers do not expose this extension model;
the installable SPM Dashboard remains the supported iOS route.

## Upgrade and compatibility

This is a feature release with no vault-format migration. Existing vaults,
recovery material, CLI commands, the Dashboard, and the original extension
remain compatible. The release archive continues to be built from the tag by
GitHub Actions and is published with a matching SHA-256 file.
