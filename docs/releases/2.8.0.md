## [2.8.0] - 2025-12-16

### Added
- Japanese localization for the entire web dashboard: header, panels, import/export copy, and web session text now translate instantly and persist per-browser thanks to a cookie-backed language selector (EN/ID/JP).

### Fixed
- Detail pages (/view, /edit, passphrase/backup viewers, authenticator live view/edit, and the password generator) now respect the same language selection so translations persist across the full workflow.

### Release steps
1. Package ZIP:
   ```bash
   zip -r Sans_Password_Manager_v2.8.0.zip spm.sh README.md CHANGELOG.md
   ```
2. Commit/tag:
   ```bash
   git add spm.sh README.md CHANGELOG.md release-2.8.0.md AGENTS.md
   git commit -m "release: v2.8.0"
   git tag v2.8.0
   git push origin main --tags
   ```
3. Publish GitHub release `v2.8.0` attaching the ZIP with the notes above.
