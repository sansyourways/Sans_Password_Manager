# Sans Password Manager 5.7.2

A fix to 5.7.1's one-click extension install. No format change.

## What changed

5.7.1 added an **Install now** button to the Dashboard's Browser extension page,
offered when the Dashboard is bound to loopback. But the documented deployment
binds the Dashboard to `127.0.0.1` **behind a public reverse proxy**, so a
loopback *bind* still serves visitors on a domain — and the button (and its
`/extension/setup` route) were offered to them too.

That is both useless and wrong for a remote visitor: the browser extension talks
to a **same-machine** native-messaging host, so it can never work across a proxy,
and running the build and host registration would happen on the **server**, not
the visitor's machine.

5.7.2 gates the button and the route on the request's **Host header** instead of
the bind address: one-click install is offered only to a **local viewer**
(`localhost` / a loopback IP). A proxied domain visitor sees the manual steps
only, exactly as intended.

## Upgrading

Reinstall or redeploy the Dashboard. Your vault is untouched. Nothing else changes.
