## [2.7.1] - 2025-12-13

### Changed
- Theme pass: AMOLED now uses solid black, Cyberpunk uses neon gradients, and Light is cleaned up for a bright modern look with theme-wide variable application.
- Disabled periodic auto-reload; rely on the existing 30s idle auto-lock instead.

### Release steps
1) Update version + docs: `VERSION=2.7.1`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.7.1.zip spm.sh README.md docs release-2.7.1.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.7.1"
   git tag v2.7.1
   git push origin main --tags
   ```
4) Create GitHub release for `v2.7.1` attaching `Sans_Password_Manager_v2.7.1.zip` and include the changelog notes above.
