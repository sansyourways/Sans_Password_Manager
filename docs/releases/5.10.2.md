# Sans Password Manager 5.10.2

A follow-up fix to 5.10.1. No vault format change, and existing vaults are
untouched.

## Each record type is its own section

5.10.1 gave each record type its own heading and an Add button that went
straight to that type's form. But the page still carried two things that made it
read as the **Records list with a filter applied** rather than a page of its
own: the type-filter chip row (`All | Certificate | Credit Card …`) and the
generic subtitle "Typed records stored in the same encrypted vault."

A type page — Certificate, API Token, Database Credentials, GPG Key, Identity
Document, Server, Wi-Fi Network, SSH Key, Software Licence, Credit Card — now:

- **drops the type-filter chip row** (the sidebar's own sub-entries already move
  between types, so the chips were redundant and were the main thing that made
  it look like a filter);
- **names its Add button after the type** — "+ Add Certificate", "+ Add API
  Token", and so on;
- uses a subtitle scoped to the type rather than the all-records one.

The **Records → All page is unchanged**: it keeps the chip row, the Type column
and the generic heading exactly as before, listing every type together.

## Upgrading

Reinstall or redeploy. Nothing about how vaults are written changes.
