## [2.7.9] - 2025-12-15

### Added
- Every copy button in the web views (passwords, secure notes, passphrases, backup codes, authenticators) now shows a toast notification so users immediately know when clipboard actions succeed or fail, even on mobile browsers.
- Header now exposes a persistent 🇺🇸/🇮🇩 dropdown; dashboard panels, table headers, and the Export/Import card translate instantly and the cookie keeps your preference for the next session.
- Save bundles now copy `spm_recovery_private.pem` (when present) so the archive contains everything needed for restores.
- Portable bundles now also pick up `spm_recovery_private.pem` whenever it lives next to the script, making both bundle types self-contained.
- Added `./spm.sh restore` (and a matching menu option) to relocate `spm_vault.gpg` and its recovery file from a portable/save folder back to `~/.spm_vault.gpg`.
- Restore updates the current session to the new vault path so lists and edits work immediately after relocating.
- Restored files are now renamed to the hidden dotfile convention (`~/.spm_vault.gpg` + `.recovery`) so they land in the standard location after exiting the bundle.

### Security
- Hardened `update` command verifies SHA-256 checksums against the signed release manifest before installing.
- `make_tmp` now relies solely on `mktemp`, eliminating race conditions when creating temporary files.
- `_spm_totp_code` passes TOTP secrets via stdin instead of command-line flags, so secrets never appear in `ps` output.
- `web` command shows a stronger warning reminding users to run the local server only on trusted networks.

### Release steps
1) Package ZIP:  
   ```bash
   zip -r Sans_Password_Manager_v2.7.9.zip spm.sh README.md CHANGELOG.md
   ```
2) Commit/tag:  
   ```bash
   git add spm.sh README.md CHANGELOG.md release-2.7.9.md AGENTS.md
   git commit -m "release: v2.7.9"
   git tag v2.7.9
   git push origin main --tags
   ```
3) Publish GitHub release `v2.7.9` attaching the ZIP with the notes above.
