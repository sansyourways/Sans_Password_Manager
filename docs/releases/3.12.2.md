# Sans Password Manager 3.12.2

This patch makes the repository README a faster, safer entry point and sends
the full operational manual to
[spm-docs.silentprotocol.top](https://spm-docs.silentprotocol.top/).

## Faster first use

The README now leads with a 60-second install and first-vault workflow. The
recovery-material warning appears directly beside initialization, before a new
user can mistake the private key for an ordinary generated file.

## Clearer product boundaries

The shorter README keeps the security model, independent-audit status,
platform support, data locations, known limitations, and who SPM is or is not
for visible without requiring readers to navigate a full manual.

Detailed installation variants, command workflows, deployment, browser
integration, synchronization, recovery, and troubleshooting remain available
in the searchable documentation site.

The hosted manual is synchronized to 3.12.2. Its desktop and mobile
screenshots, browser-extension setup image, and animated dashboard tour were
recaptured from this release candidate using only a disposable synthetic vault.

## Compatibility

This is a documentation-only product change. There is no vault-format,
cryptography, recovery, command, dashboard, extension, or data-handling change.
Rolling back to 3.12.1 does not require a vault migration.
