## [2.6.1] - 2025-12-13

### Changed
- Easy generator now builds human-memorable word-based passwords; secure mode remains random.
- Generator UI/CLI now include toggles for uppercase, lowercase, numbers, and symbols (easy mode maps slider to word count).

### Release steps
1) Update version + docs: `VERSION=2.6.1`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.6.1.zip spm.sh README.md docs release-2.6.1.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.6.1"
   git tag v2.6.1
   git push origin main --tags
   ```
4) Create GitHub release for `v2.6.1` attaching `Sans_Password_Manager_v2.6.1.zip` and include the changelog notes above.
