## [2.5.2] - 2025-12-13

### Fixed
- Clipboard buttons now use a secure fallback (temporary textarea) when `navigator.clipboard` is unavailable, ensuring bookmarklet/secret copies work reliably.

### Release steps
1) Update version + docs: `VERSION=2.5.2`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.5.2.zip spm.sh README.md docs release-2.5.2.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.5.2"
   git tag v2.5.2
   git push origin main --tags
   ```
4) Create GitHub release for `v2.5.2` attaching `Sans_Password_Manager_v2.5.2.zip` and include the changelog notes above.
