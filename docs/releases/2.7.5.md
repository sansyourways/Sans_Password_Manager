## [2.7.5] - 2025-12-13

### Added
- Export command (`./spm.sh export <csv|json> [file]`) to dump all data types (passwords, notes, passphrases, authenticators, backup codes) into CSV or JSON. Also available from the interactive menu.

### Changed
- Version bumped to 2.7.5; docs updated (README, CHANGELOG).

### Release steps
1) Ensure `VERSION` in `spm.sh` is `2.7.5` and docs are updated (done).
2) Package release ZIP:  
   ```bash
   zip -r Sans_Password_Manager_v2.7.5.zip spm.sh README.md docs CHANGELOG.md LICENSE
   ```
3) Commit and tag:  
   ```bash
   git add spm.sh README.md CHANGELOG.md release-2.7.5.md docs AGENTS.md
   git commit -m "release: v2.7.5"
   git tag v2.7.5
   git push origin main --tags
   ```
4) Publish GitHub release for `v2.7.5` attaching `Sans_Password_Manager_v2.7.5.zip` and include the changelog notes above.
