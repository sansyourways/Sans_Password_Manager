# Sans Password Manager 5.7.1

One-click browser-extension install from the Dashboard. No format change: 5.7.1
reads and writes exactly the vaults 5.7.0 does.

## What's new

### "Install now" on the Dashboard's Browser extension page

5.7.0 made extension installation first-class from the CLI, the interactive menu
and a Dashboard page of manual steps. 5.7.1 makes the Dashboard page **one click**
where it safely can be.

A web page **cannot** silently install a browser extension — Chrome and Firefox
forbid it, which is exactly the boundary that stops a page from pushing one onto
you. What the Dashboard *can* do is everything up to that boundary, because its
backend is the local SPM process on your machine:

- The **Browser extension** page shows an **Install now** button when the
  Dashboard is bound to loopback and the extension files are present on this host.
- Clicking it POSTs to a session- and CSRF-authenticated `/extension/setup`
  route, which runs the bundled `setup.sh` here: it builds the unpacked extension
  and registers the native-messaging host.
- The page then shows the one remaining step, which is the browser's own rule:
  open `chrome://extensions`, enable Developer mode, and **Load unpacked** the
  built folder (the page names it).

The button is **refused on a non-loopback bind** — building files and touching a
browser on a remote host is never what a visitor to a published Dashboard wants,
so there it shows the manual steps only.

`install.sh` now also places the extension source under
`~/.local/share/spm/browser-extension-universal`, so both `spm extension setup`
and the Dashboard's Install now work after an ordinary install of the single
`spm` script.

## Compatibility

- **No format change.** 5.7.1 stays on vault format 6.
- **Loopback only, authenticated.** The one-click route needs an active session
  and a CSRF token and answers only on a loopback Dashboard.

## Upgrading

Reinstall or redeploy the Dashboard. Your vault is untouched. On a local
Dashboard, the Browser extension page will show **Install now**.
