# Sans Password Manager 3.13.0

The Dashboard now ships in twelve languages, including right-to-left Arabic,
and a translation can be contributed without touching any code.

## Translations became contributable

The roadmap asked for "optional localization contributions beyond English,
Indonesian, and Japanese". The obstacle was never that translations were
missing. It was that contributing one meant hand-editing a JavaScript object
literal, inside a Python string, inside a file concatenated into a generated
shell script — and getting two levels of escaping right. The regression suite
already carried a test whose only job was to catch that escaping going wrong.

Catalogues now live in `locales/<code>.json`: plain JSON, `meta` and `strings`,
no escaping traps. `tools/build-locales.py` folds them into a generated region
in `src/spm_web_server.py`, and `./build.sh --check` verifies that region is
current, the same discipline `spm.sh` itself is held to.
`tools/i18n-lint.py` is what a contributor runs before opening a pull request:
it refuses a catalogue that is missing a key, carries one English does not,
contains markup, or drops a placeholder such as `{n}`.

Two things follow from the new shape. A page now carries only the language it
is in plus English, with the rest fetched from `/locale?lang=<code>` when
somebody switches — at twelve languages that is most of the payload. And the
catalogue reaches the browser through `json.dumps` instead of a hand-typed
literal, so the escaping hazard stops existing rather than being tested for.

## Nine new languages, honestly labelled

Arabic, German, Spanish, French, Hindi, Korean, Brazilian Portuguese, Russian
and Simplified Chinese join English, Indonesian and Japanese.

None of the nine has been reviewed by a speaker, and the interface says so.
They are marked **(β)** in the picker, and while one is active the page carries
a line stating that the translation is unchecked and that the English text is
authoritative where a warning matters. That caveat is not boilerplate: some of
these strings describe actions nothing can undo — that a forgotten master
password is unrecoverable, that changing it re-encrypts the whole vault, that
deleting a record deletes its password history with it. A translation that
softens one of those is worse than no translation.

Correcting one takes no programming. The procedure is in the Languages section
of the documentation.

## Right-to-left

Arabic is not a word swap. Physical margins, paddings and borders throughout
the stylesheet became logical properties, and positioned decorations — the
active-navigation marker, the search icon, the shortcut hint, the toast —
became insets, so the sidebar, the navigation rail and the table columns
genuinely mirror.

Two further decisions were needed. The fixed-width type the Console theme is
built on is dropped for right-to-left locales: a cursive script rendered in a
monospace face stops joining and reads as a row of loose letters. And machine
values keep their own direction inside the mirrored layout — a password, a URL,
a Base32 secret and the vault path stay left-to-right, because reordering a
file path around its own slashes makes it wrong rather than merely foreign.

## What the tests could not see

Two defects passed every assertion in the suite and were found only by
screenshotting the running application.

The unreviewed-translation notice rendered on *every* language, including the
maintained ones — telling an English reader that their English was unchecked.
The notice ships with the `hidden` attribute and is revealed by script, but
giving the class a `display` rule outranks the user agent's `[hidden]` rule, so
it was never hidden at all.

The search icon sat on top of its own placeholder in Arabic. The input reserved
room for the icon with a four-value `padding` shorthand, which is physical and
does not mirror, so the space stayed on the left while the icon moved right.

Both now have guards, and both guards were mutation-tested — as were the
per-page catalogue, the document direction, the RTL font stack, the
left-to-right pinning of machine values, the `/locale` route, and each of the
lint's refusals.

## Compatibility and rollback

Documentation, interface and build tooling only. No change to the vault format,
the key wrapping, the recovery file or the installer. Revert to v3.12.4 to go
back; nothing needs converting, and a browser holding an unsupported language
cookie falls back to English.
