## [2.7.3] - 2025-12-13

### Changed
- Light theme readability improvements: themed tables/wrappers, themed card text/headings, and softer button styling.

### Release steps
1) Update version + docs: `VERSION=2.7.3`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.7.3.zip spm.sh README.md docs release-2.7.3.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.7.3"
   git tag v2.7.3
   git push origin main --tags
   ```
4) Create GitHub release for `v2.7.3` attaching `Sans_Password_Manager_v2.7.3.zip` and include the changelog notes above.
