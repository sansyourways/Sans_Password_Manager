## [2.5.0] - 2025-12-13

### Added
- Authenticator (TOTP) entries with CLI and menu flows to add/list/view/edit/delete, including configurable refresh intervals.
- Web mode authenticator dashboard with live code view (auto-refresh) and JSON endpoint for dynamic updates.

### Changed
- Doctor output and interactive menus now include authenticators.

### Release steps
1) Update version + docs: `VERSION=2.5.0`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.5.0.zip spm.sh README.md docs release-2.5.0.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.5.0"
   git tag v2.5.0
   git push origin main --tags
   ```
4) Create GitHub release for `v2.5.0` attaching `Sans_Password_Manager_v2.5.0.zip` and include the changelog notes above.
