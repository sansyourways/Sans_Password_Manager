## [2.5.6] - 2025-12-13

### Fixed
- Added dual cookies (Lax + SameSite=None; Secure) so bookmarklets can include session credentials when used cross-site over HTTPS.

### Release steps
1) Update version + docs: `VERSION=2.5.6`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.5.6.zip spm.sh README.md docs release-2.5.6.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.5.6"
   git tag v2.5.6
   git push origin main --tags
   ```
4) Create GitHub release for `v2.5.6` attaching `Sans_Password_Manager_v2.5.6.zip` and include the changelog notes above.
