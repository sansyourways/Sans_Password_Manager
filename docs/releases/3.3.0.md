# Sans Password Manager 3.3.0

A dashboard release. Two controls that looked fine and did nothing now work,
and the interface gained the motion layer its design system always implied.

## The language picker never worked

The dashboard ships English, Indonesian and Japanese as one inline dictionary.
That dictionary is written inside a Python string, so an escape meant for
JavaScript was consumed by Python first: `\"` in the source reached the browser
as a bare quote, ended the JavaScript string early, and took the entire
dictionary down with a `SyntaxError`.

Nothing appeared to break. Every element in the markup carries an English
fallback, so the page rendered correctly and the only symptom was that
selecting Indonesian or Japanese did nothing whatsoever. It shipped in every
release that contained the string, and no test caught it, because every test
asserted on rendered HTML — which was right — rather than on whether the script
that translates it could be parsed.

The regression suite now decodes the Python literal, parses the dictionary the
way the browser does, and checks the three languages against each other for
missing and surplus keys.

## The desktop hamburger did nothing

The sidebar's menu button was rendered at every width and then hidden by CSS
above 900px. On a desktop it was markup that could not be pressed.

It now collapses the sidebar to an icon rail and back. The choice is
remembered, and applied before the first paint — reading it later renders the
sidebar expanded and then snaps it, which reads as a glitch rather than as a
setting. Labels are clipped rather than removed, so a screen reader still
announces every item, and each one carries a tooltip that translates.

## Motion

Built to the Console (CNS-18) rules the dashboard already follows.

The page's top-level blocks arrive in reading order, one step apart, once per
load — a transcript printing. The session indicator pulses only while the idle
countdown is actually running and stops the moment it pauses, so it reports
state rather than decorating the sidebar. Entrances are slower than exits,
because a departing surface has already been decided about and matching the two
makes dismissal feel sticky.

All of it is additive. The hiding rules sit behind an explicit
`prefers-reduced-motion: no-preference` query *and* behind a class only
JavaScript sets, so with scripts blocked, motion disabled, or the preference
unreported, the page renders at its final state. Nothing is ever left
invisible.

Deliberately absent: no decorative particles, cursor effects or scroll-triggered
reveals. The motion specification permits those on a landing page and nowhere
else, and explicitly not on a dashboard — a surface people open every day is
where ornament turns into friction.

## Progress bars stopped relayouting

The idle-lock countdown, the TOTP ring and the generator's strength meter all
animated `width`, which forces layout on every frame. The countdown did it once
a second for the life of a session. All three now animate `transform`, which
the compositor handles.

## Upgrade and compatibility

No vault-format migration. Vaults, recovery material, CLI commands and the
browser extension are unchanged from 3.2.0. Restarting the dashboard signs out
existing browser sessions, as any restart does.
