## [2.4.0] - 2025-12-13

### Added
- Passphrase vault with CLI + menu (`passphrase-add/list/view/delete`) and master-password re-check on view.
- Auto updater: `./spm.sh update` downloads the latest ZIP release, extracts `spm.sh`, and installs to `/usr/local/bin/spm` (uses sudo when available).
- Web mode now includes Passphrases and Backup Codes sections (add/edit/view/delete) plus auto-refresh every 5 seconds, refresh button in header, and footer copyright/version.

### Changed
- Interactive menu renumbered to include Passphrases; doctor now reports passphrase/backup-code counts.
- Help and editor format notes now include `PASSPHRASE` rows.

### Fixed
- Master password re-verification no longer double-prompts; uses the cached master password before comparing.

### Release steps
1) Update version + docs (done in this repo): `VERSION=2.4.0`, README, CHANGELOG, release notes.
2) Build ZIP bundle: `zip -r Sans_Password_Manager_v2.4.0.zip spm.sh README.md docs release-2.4.0.md CHANGELOG.md`.
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.4.0"
   git tag v2.4.0
   git push origin main --tags
   ```
4) Create GitHub release for `v2.4.0` attaching `Sans_Password_Manager_v2.4.0.zip` and include the changelog notes above.
5) Sanity check installer: on a clean shell, run `./spm.sh update` and confirm it installs `/usr/local/bin/spm`.
