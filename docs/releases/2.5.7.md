## [2.5.7] - 2025-12-13

### Changed
- Removed the web autofill bookmarklet feature and its UI; copy buttons remain for viewing secrets.

### Release steps
1) Update version + docs: `VERSION=2.5.7`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.5.7.zip spm.sh README.md docs release-2.5.7.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.5.7"
   git tag v2.5.7
   git push origin main --tags
   ```
4) Create GitHub release for `v2.5.7` attaching `Sans_Password_Manager_v2.5.7.zip` and include the changelog notes above.
