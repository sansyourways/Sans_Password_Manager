## [2.7.0] - 2025-12-13

### Added
- Web themes (Dark, AMOLED, Cyberpunk, Light) with a header selector and persistent preference.
- Header now shows the current version and auto-checks GitHub for the latest release on load; manual “Check update” button included.

### Release steps
1) Update version + docs: `VERSION=2.7.0`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.7.0.zip spm.sh README.md docs release-2.7.0.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.7.0"
   git tag v2.7.0
   git push origin main --tags
   ```
4) Create GitHub release for `v2.7.0` attaching `Sans_Password_Manager_v2.7.0.zip` and include the changelog notes above.
