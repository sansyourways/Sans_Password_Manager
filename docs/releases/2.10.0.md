# Sans Password Manager 2.10.0

SPM 2.10 is a local-first capability release built around encrypted data,
explicit trust boundaries, bounded storage, and conflict refusal.

## Added

- Encrypted password history and confirmed rollback
- Weak/reused/old credential security dashboard in CLI and web overview
- Verified automatic encrypted backups
- Recipient-encrypted emergency kits
- Exact-domain Chrome/Chromium native autofill bridge
- Digest-verified encrypted attachments
- Named independent vault profiles
- Conflict-safe filesystem synchronization
- Platform passkey metadata without exporting private passkey keys

See `docs/FEATURE_PLAN_2.10.md` for architecture, limitations, and validation.
