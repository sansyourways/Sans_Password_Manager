## [2.7.7] - 2025-12-13

### Added
- Export now accepts additional formats: yaml/yml, xml, sql, ini, psv, rst, and jsonl (alias of ndjson), alongside csv/json. Menu prompt stays concise (csv/json).

### Changed
- Version bumped to 2.7.7.

### Release steps
1) Package ZIP:  
   ```bash
   zip -r Sans_Password_Manager_v2.7.7.zip spm.sh README.md docs CHANGELOG.md LICENSE
   ```
2) Commit/tag:  
   ```bash
   git add spm.sh README.md CHANGELOG.md release-2.7.7.md AGENTS.md docs
   git commit -m "release: v2.7.7"
   git tag v2.7.7
   git push origin main --tags
   ```
3) Publish GitHub release `v2.7.7` attaching the ZIP and include the notes above.
