## [2.6.0] - 2025-12-13

### Added
- Password generator in CLI (`./spm.sh generate`) and web with mode toggles (secure/easy/numeric), optional symbols, length slider, and strength/crack-time estimates.

### Changed
- Main interactive menu and web dashboard now include a Password Generator entry; autofill bookmarklet remains removed.

### Release steps
1) Update version + docs: `VERSION=2.6.0`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.6.0.zip spm.sh README.md docs release-2.6.0.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.6.0"
   git tag v2.6.0
   git push origin main --tags
   ```
4) Create GitHub release for `v2.6.0` attaching `Sans_Password_Manager_v2.6.0.zip` and include the changelog notes above.
