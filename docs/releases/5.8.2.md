# Sans Password Manager 5.8.2

Four bug fixes found by a post-release audit, shipped together. No vault format
change, and existing vaults are untouched.

## Sync is fast-forward only, in both directions

The synchronisation is a whole-file, three-way **conflict check** — it compares
the local, remote and last-synced (base) digests. It refused only when *both*
the local and the remote had changed since the base, which left two silent
data-loss holes when only one side had advanced:

- **`pull`** with unpushed local edits and an unchanged remote replaced the local
  vault with the older remote — discarding the local edits.
- **`push`** with an advanced remote and an unchanged local published the stale
  local — reverting the remote and losing another device's update.

Both are now refused with a message that says which way to sync, and only a true
fast-forward proceeds. (There is still no automatic per-record merge; divergence
is refused, not merged.)

## Time-lock open bounds its work factor

An emergency kit's time-lock puzzle is opened from a file the recipient was
handed, so its parameters are untrusted. `timelock_unseal` read the squaring
count `t` and the modulus `n` straight from that file, so a crafted or tampered
kit could set them arbitrarily high and make opening it never finish. The work
factor, the modulus size and the payload size are now bounded before any
squaring begins — a real kit is far inside the limits — and `--delay-hours` is
clamped to the same ceiling at creation.

## Theme CSS cleanup

The Dashboard stylesheet still carried the previous theme system —
`theme-dark`, `theme-amoled` and `theme-light` blocks that are never applied,
plus a duplicate `theme-cyberpunk` — and defined a dark `--bg-grad` on the bare
`body` that only a later rule kept from showing. The dead blocks are removed and
the body background now reads `var(--bg)` directly, so the dark gradient can no
longer leak onto the light themes.

## Edgerunner border in right-to-left languages

The Edgerunner theme thickened the card accent border with the physical
`border-left-width`, which put it on the wrong side in right-to-left Arabic. It
now uses the logical `border-inline-start-width`, so it flips with the layout.

## Upgrading

Reinstall or redeploy. Nothing about how vaults are written changes.
