## [2.5.4] - 2025-12-13

### Fixed
- Prevented JSON module shadowing in web server responses so bookmarklets no longer hit “local variable 'json'” errors.

### Release steps
1) Update version + docs: `VERSION=2.5.4`, README, CHANGELOG, release notes.
2) Build ZIP bundle:  
   `zip -r Sans_Password_Manager_v2.5.4.zip spm.sh README.md docs release-2.5.4.md CHANGELOG.md`
3) Tag and push (from repo root):  
   ```bash
   git add .
   git commit -m "release: v2.5.4"
   git tag v2.5.4
   git push origin main --tags
   ```
4) Create GitHub release for `v2.5.4` attaching `Sans_Password_Manager_v2.5.4.zip` and include the changelog notes above.
