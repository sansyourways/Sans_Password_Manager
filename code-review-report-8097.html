Architecture overview

SPM is a single executable Bash application. It embeds a Python HTTP server, HTML/CSS/JavaScript templates, GPG vault operations, import/export handlers, recovery flows, and the interactive CLI/TUI.

Web requests are served by SPMServer and Handler using a threaded HTTP server. Sessions are held in process memory, with a 30-minute TTL. Imports are capped at 1 MiB and generic POST bodies at 2 MiB.
